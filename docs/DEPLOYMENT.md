# 部署说明文档\n\n## 系统要求\n\n- Java 17 或更高版本\n- MySQL 8.0 或更高版本\n- Redis 6.0 或更高版本\n- Node.js 16 或更高版本\n- 微信开发者工具（小程序开发和测试）\n\n## 后端部署\n\n### 1. 数据库初始化\n\n```bash\nmysql -u root -p < database/yishijie.sql\n```\n\n### 2. 修改配置文件\n\n编辑 `backend/src/main/resources/application.yml`\n\n```yaml\nspring:\n  datasource:\n    url: jdbc:mysql://localhost:3306/yishijie?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai\n    username: root\n    password: your_password\n  redis:\n    host: localhost\n    port: 6379\n    password: \n\njwt:\n  secret: your-secret-key\n  expiration: 86400000\n```\n\n### 3. 构建和运行\n\n```bash\ncd backend\nmvn clean install\nmvn spring-boot:run\n```\n\n后端服务将在 `http://localhost:8080` 启动\n\n## 小程序部署\n\n### 1. 安装依赖\n\n```bash\ncd miniprogram\nnpm install\n```\n\n### 2. 配置API地址\n\n编辑 `miniprogram/app.js`，修改 `apiBase`：\n\n```javascript\nglobalData: {\n  apiBase: 'https://your-api-domain/api'\n}\n```\n\n### 3. 在微信开发者工具中打开\n\n1. 打开微信开发者工具\n2. 点击\"文件\" -> \"打开项目\"\n3. 选择 `miniprogram` 目录\n4. 输入 AppID（需从微信公众平台获取）\n5. 点击\"打开\"\n\n## 管理后台部署\n\n### 1. 安装依赖\n\n```bash\ncd admin\nnpm install\n```\n\n### 2. 配置API地址\n\n编辑 `.env.local`：\n\n```\nVITE_API_BASE_URL=http://localhost:8080/api\n```\n\n### 3. 开发运行\n\n```bash\nnpm run dev\n```\n\n访问 `http://localhost:5173`\n\n### 4. 生产构建\n\n```bash\nnpm run build\n```\n\n生成的文件在 `dist` 目录中，可部署到 Nginx 或其他静态服务器\n\n## 生产环境部署\n\n### Docker 部署\n\n创建 `docker-compose.yml`：\n\n```yaml\nversion: '3.8'\nservices:\n  mysql:\n    image: mysql:8.0\n    environment:\n      MYSQL_ROOT_PASSWORD: root123456\n      MYSQL_DATABASE: yishijie\n    ports:\n      - \"3306:3306\"\n    volumes:\n      - mysql_data:/var/lib/mysql\n\n  redis:\n    image: redis:7.0\n    ports:\n      - \"6379:6379\"\n\n  backend:\n    build: ./backend\n    ports:\n      - \"8080:8080\"\n    depends_on:\n      - mysql\n      - redis\n    environment:\n      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/yishijie\n      SPRING_REDIS_HOST: redis\n\nvolumes:\n  mysql_data:\n```\n\n运行：\n\n```bash\ndocker-compose up -d\n```\n"
