# 医视界平台 - API 文档\n\n## 基本说明\n\n- 基础URL: `http://localhost:8080/api`\n- 请求方式: RESTful\n- 数据格式: JSON\n- 认证方式: JWT Bearer Token\n\n## 认证接口\n\n### 用户登录\n\n**POST** `/user/phone-login`\n\n请求参数:\n```json\n{\n  \"phone\": \"13800138000\",\n  \"password\": \"password123\"\n}\n```\n\n响应:\n```json\n{\n  \"code\": 0,\n  \"message\": \"登录成功\",\n  \"data\": {\n    \"token\": \"eyJhbGciOiJIUzUxMiJ9...\",\n    \"userInfo\": {\n      \"id\": 1,\n      \"username\": \"user1\",\n      \"phone\": \"13800138000\",\n      \"realName\": \"张三\"\n    }\n  }\n}\n```\n\n### 微信登录\n\n**POST** `/user/wechat-login`\n\n请求参数:\n```json\n{\n  \"nickName\": \"微信昵称\",\n  \"avatarUrl\": \"头像URL\",\n  \"gender\": 1\n}\n```\n\n## 课程接口\n\n### 获取课程列表\n\n**GET** `/course/list?page=1&limit=10`\n\n请求头:\n```\nAuthorization: Bearer {token}\n```\n\n响应:\n```json\n{\n  \"code\": 0,\n  \"message\": \"成功\",\n  \"data\": [\n    {\n      \"id\": 1,\n      \"name\": \"中老年健康养生课程\",\n      \"price\": 99.00,\n      \"teacher\": \"李医生\",\n      \"enrollCount\": 50\n    }\n  ]\n}\n```\n\n## 推广接口\n\n### 获取我的推广信息\n\n**GET** `/promotion/my-info`\n\n请求头:\n```\nAuthorization: Bearer {token}\n```\n\n响应:\n```json\n{\n  \"code\": 0,\n  \"message\": \"成功\",\n  \"data\": {\n    \"promotionCode\": \"PROMO123456\",\n    \"referralCount\": 5,\n    \"totalReward\": 500.00\n  }\n}\n```\n"
