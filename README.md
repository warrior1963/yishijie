# 海南医视界中老年健康旅居平台小程序

## 项目概述

面向退休干部、中老年人群，打造的集：
- 健康知识学习
- 健康旅居报名
- 专家课程
- 健康产品购买
- 学员社群运营
- 健康档案管理

于一体的综合服务平台。

## 项目结构

```
yishijie/
├── miniprogram/          # 微信小程序前端（云开发）
├── backend/              # Java 后端 API
├── admin/                # 后台管理系统
├── database/             # 数据库设计
└── docs/                 # 文档
```

## 技术栈

- **前端**：微信小程序 + 云开发
- **后端**：Java SpringBoot + MySQL
- **管理后台**：Vue3 + Element Plus

## 快速开始

### 小程序开发
```bash
cd miniprogram
# 在微信开发者工具中打开
```

### 后端开发
```bash
cd backend
mvn clean install
mvn spring-boot:run
```

### 管理后台
```bash
cd admin
npm install
npm run dev
```

## 核心模块

1. **首页模块** - 品牌展示、老师、旅居项目、课程、产品
2. **旅居模块** - 项目列表、详情、报名、支付
3. **课程系统** - 视频/图文/直播课程
4. **商城系统** - 产品分类、下单、支付
5. **会员系统** - 个人中心、健康档案、家属端
6. **社群运营** - 打卡、签到、互动
7. **推广系统** - 邀请码、推广海报、佣金追踪
8. **后台管理** - 数据统计、内容管理、运营管理

## 开发说明

- 一期不做原生 APP，仅做微信小程序
- 重点是后台逻辑，而非页面花里胡哨
- 用户群体为老年人，重点是易用性和信任感
